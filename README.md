# Stima netto RAL 2026

Prototipo web che stima il netto annuale e il netto mensile medio a partire dalla RAL di un lavoratore dipendente standard residente a Milano nel 2026.

## Stack

- React
- TypeScript
- Vite
- Vitest
- ESLint

## Comandi

```bash
npm install
npm run dev
npm test
npm run lint
npm run build
```

È disponibile anche `npm run typecheck` per verificare TypeScript separatamente dalla build.

Scope, assunzioni, fonti e metodologia saranno documentati completamente nella milestone successiva.
